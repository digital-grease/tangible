# Security Policy

Tangible is pre-release and does not yet have a supported-version matrix.

Do not disclose suspected vulnerabilities in a public issue. Until a dedicated private reporting channel is configured, contact the repository owner directly with:

- affected commit or version
- impact
- reproduction steps
- logs or fixtures with secrets removed
- suggested mitigation if known

Reports involving path traversal, command construction, SSRF, worker authentication, device access, artifact corruption, or burn-job duplication should be treated as security-sensitive.
